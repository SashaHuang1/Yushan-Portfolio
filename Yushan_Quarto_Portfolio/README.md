# Yushan Huang — Quarto Portfolio

## Build

1. Install Quarto (https://quarto.org) and open this folder in RStudio or a terminal.
2. Run `quarto render` in the project folder.
3. Preview locally with `quarto preview`.
4. In GitHub repository Settings > Pages, deploy from the `main` branch `/docs` folder. Make sure the generated `docs/` folder is committed.
5. Add GA4 only after creating a GA4 property; do not publish private analytics data.

## Important

This is a source-ready draft, not a published website. The dashboard is a qualitative CEP workflow overview because verified quantitative CEP results were not supplied. Project descriptions and resume should be reviewed before public publication. No fabricated business outcomes are included.
